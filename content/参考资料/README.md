## 📝 资料定位

这些深度文章体现了产品的价值观和理念，是写小红书、公众号、抖音文案时的参考素材。

**不是**：
- ❌ 直接发布的自媒体内容
- ❌ 产品内的用户可见内容
- ❌ 完整的理论体系

**而是**：
- ✅ 灵感来源和思考素材
- ✅ 产品理念的深度阐释
- ✅ 创作时的参考资料

## 🔖 小红书笔记采集（2026-09-11 起）

刷到值得记的笔记，一条命令入库：

```bash
echo '<笔记链接>' > /tmp/note-url.txt && npm run collect:note
```

脚本（`scripts/collect-note.mjs`）会用 ego-browser（你的登录态）打开笔记页，抓**标题 / 正文 / 作者 / 赞藏评 / 话题标签 / 首图**，落盘两处：

- `content/参考资料/<标题>.md`（frontmatter 带原文数据 + 待拆解标记）
- `public/inspiration/<id>.jpg`（首图，灵感卡直接展示）

采完两步收尾：① 跑 `npm run gen:data`；② **让 AI 按下方拆解规范补 frontmatter 的 `analysis:` 块**——拆完卡片上的「AI 拆解」徽章自动亮起。

边界：只采自己浏览、用于个人学习参考的单条笔记；不批量、不碰他人后台。

## 🤖 AI 拆解规范（2026-09-11 起）

每篇参考资料在 frontmatter 的 `analysis:` 块维护一份「爆款拆解」，灵感库页面会渲染成可展开的拆解卡。字段固定五个：

```yaml
---
analysis:
  titleStructure: 标题用了什么句式/结构，为什么能带来点开率
  hook: 开头前三句靠什么钩住人
  structure: 全文行文骨架（一段话讲清）
  steal: 可直接偷的句式/技巧/金句结构
  topics: 适用到我们账号的选题方向
analyzedAt: YYYY-MM-DD
---
```

- **新采集的资料入库时必须拆**（让 AI 按此规范生成 frontmatter），没有拆解的条目在灵感库不显示徽章
- 拆的是「结构和技巧」，不是内容本身——内容是别人的，结构才是可以复用的
- 2026-09-11 已完成现存 7 篇的拆解

## 💡 使用建议

### 1. 提炼金句
从长文中提取适合社交媒体的短句：
- 一句话观点
- 打动人的洞察
- 可传播的判断

### 2. 深度改编
将长文改编为公众号或小红书长文：
- 保持核心观点
- 调整表达方式
- 增加具体案例

### 3. 理念传达
在创作时参考这些文章的：
- 价值观角度
- 思考方式
- 表达风格

### 4. 灵感触发
当不知道写什么时：
- 浏览这些文章找灵感
- 看哪个观点能引发共鸣
- 结合当下场景重新表达

## 🎯 创作原则

### 不可直接复制
- ❌ 整段复制到自媒体
- ❌ 只改几个字就发布
- ❌ 假装是原创观点

### 可以参考
- ✅ 提取核心观点重新表达
- ✅ 用自己的话说出来
- ✅ 结合具体场景举例
- ✅ 保持价值观一致

### 示例对比

**❌ 错误做法**（直接复制）：
```
"从时间看吸引，纯粹的往往最动人。
一个人如果能长期保持对某件事的专注，
那种纯粹的投入本身就是最大的魅力。"
```

**✅ 正确做法**（重新表达）：
```
我发现很有魅力的人
都会长期做一件自己喜欢的事

不是为了成为谁
只是真的喜欢

这种纯粹的投入
本身就很动人
```
