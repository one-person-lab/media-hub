# content/ —— 你的内容库

这个目录就是数据源。工作台不连数据库，**你写的 markdown 文件就是全部数据**。

```
content/
└── 自媒体运营/
    ├── 00-运营手册.md          # 创作约束，交给 AI 写稿时读（把你的规范写这里）
    ├── 发布排期/
    │   ├── 待发布/             # 草稿；文件即选题
    │   └── 已排期/YYYY-MM/     # 排期后的稿子
    ├── 创作素材/归档/          # 灵感与素材
    └── 对标账号/               # 对标账号笔记（data 文件自带 frontmatter）
```

## 约定

- 新增内容 = 新增 md 文件，然后 `npm run gen:data`（dev/build 会自动跑）
- 排期靠**文件所在目录**表达，状态由「是否有发布链接」推导
- frontmatter 用 YAML，缺少字段会用默认值兜底

> 采集来的第三方笔记请只作个人学习参考，不要随仓库公开分发。
